# Target Profiles

Target profiles convert a public role description into a focused path through
Platform BreakFix Labs.

They are not company question dumps. Unless a source explicitly says otherwise,
questions and scenarios in a profile are role-derived practice material, not
claims about a company's interview process.

## Profile contract

Every profile should contain:

- The public source, job identifier, location, and review date
- A requirement-to-lab coverage matrix
- A prioritized BreakFix lab backlog
- A mock interview loop
- Staff/senior behavioral and system-design prompts where applicable
- Clear labels separating sourced facts from inferred preparation
