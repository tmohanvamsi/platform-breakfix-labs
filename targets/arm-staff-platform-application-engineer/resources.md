# External Resources

No reliable Arm-specific Platform/DevOps interview repository was located when
this profile was created. The following public repositories are useful by domain,
but none should be described as Arm's interview material.

## Practice repositories

- <https://github.com/NotHarshhaa/ai-platform-engineering-handbook> — AI platform,
  MLOps, system-design, and scenario coverage
- <https://github.com/MewsSystems/tech-platform-engineering-test> — public platform
  engineering take-home exercise using containers and infrastructure as code
- <https://github.com/bjss/bjss-careers-aws> — public AWS/Terraform platform
  engineering technical exercise
- <https://github.com/devops-interviews/devops-interview-questions> — hands-on
  DevOps/SRE questions and solutions
- <https://github.com/shospodarets/awesome-platform-engineering> — internal
  developer platform tools and platform-engineering references
- <https://github.com/litu54/DevOps-Interview-Guide> — community-submitted company
  interview experiences; no Arm-specific entry was located during review

## Usage rule

Extract a scenario or concept, reproduce it locally, and write your own evidence-led
answer. Do not memorize repository wording and do not claim a community-submitted
question is verified unless its source can be independently established.
